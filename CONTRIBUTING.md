# Contributing to Cerberus

Thank you for your interest in Cerberus. This is a **closed-source, proprietary project** developed and maintained by LamiaFabrica / D Hargreaves. External contributions are not accepted at this time.

## Bug Reports

If you have a valid licence and encounter a bug, open a GitHub Issue with:

- OS and hardware (CPU, GPU, NPU)
- Build environment (MinGW-W64 version, CMake version)
- Steps to reproduce
- Expected vs. actual behaviour
- Relevant log output (set `HQ_LOG_LEVEL=DEBUG` before running)

## Security Vulnerabilities

Do **not** open a public issue for security vulnerabilities. Follow the process in [SECURITY.md](SECURITY.md).
